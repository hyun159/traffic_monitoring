## Bastion 서버 root계정에 윈도우 호스트 pub키 등록
## 비밀번호 로그인 비활성화
```
vi /root/.ssh/authorized_keys

vi /etc/ssh/sshd_config

PubkeyAuthentication yes
PasswordAuthentication no
PermitRootLogin prohibit-password
```

## 2.배스쳔 nat망, 내부망 네트워크 인터페이스 활성화

```
nat망 10.0.2.15
내부망 192.168.0.2/28

내부망 IP 활성화
nmcli con show
ip link set enp0s8 up # 커널에서 enp0s8 활성화
nmcli con add type ethernet ifname enp0s8 con-name enp0s8 # Networkmanager 프로파일활성화
nmcli com mod enp0s8 ipv4.address 192.168.0.2/28
nmcli con mod enp0s8 ipv4.metho manual
nmcli con mod enp0s8 ipv4.gateway ""
nmcli con mod enp0s8 ipv4.never-default yes # 인터넷 기본경로 비활성화
nmcli con up enp0s8
```

## 각 노드 내부망 활성화
```
web(nginx) : 192.168.0.3/28
-> NAT 인터페이스 443포트 포트포워딩 (클라이언츠 요청 경로)

was(app) : 192.168.0.4/28
-> NAT만 설정 , 포트포워딩 X (서버가 먼저 API 요청하므로)

Redis  : 192.168.0.5/28

DB  : 192.168.0.6/28
```

## 각 노드에 배스쳔 공개키 등록 및 비밀번호 로그인 비활성화
```
ssh-keygen -t ed25519
ssh-copy-id 계정명@192.168.0.x

vi /etc/ssh/sshd_config
PubkeyAuthentication yes
PasswordAuthentication no
PermitRootLogin prohibit-password
```
