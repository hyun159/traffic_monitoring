## 마스터 서버 root계정에 윈도우 호스트 pub키 등록
## 비밀번호 로그인 비활성화
```
vi /master/.ssh/authorized_keys

vi /etc/ssh/sshd_config

PubkeyAuthentication yes
PasswordAuthentication no
PermitRootLogin prohibit-password
```

## en0ps3 - nat
## enp0s8 - 내부망

```
nat망 10.0.2.15
내부망 192.168.0.2/28

내부망 IP 활성화
nmcli con show
ip link set enp0s8 up # 커널에서 enp0s8 활성화
nmcli con add type ethernet ifname enp0s8 con-name enp0s8 # Networkmanager 프로파일활성화
nmcli con mod enp0s8 ipv4.address 192.168.0.2/28
nmcli con mod enp0s8 ipv4.method manual
nmcli con mod enp0s8 ipv4.gateway ""
nmcli con mod enp0s8 ipv4.never-default yes # 인터넷 기본경로 비활성화
nmcli con up enp0s8
```
