
# 싱글 스레드
```
GET SET SADD 명령어 실행은 메인 스레드가 동작함.
Redis 6.0 버전 부터 네트워크 패킷 읽기,쓰기는 I/O스레드가 멀티스레드로 동작.

수 많은 GET, SET 패킷을 I/O 스레드가 병렬로 읽어와 메모리에 정렬.

메인 스레가 GET, SET을 하나씩 처리함.
```

# 인메모리 영속성
```
주로 데이터를 메모리에 저장,
영속성을 보장하기 위한 방법

RDB -> 특정 시간마다 전체 스냅샷을 디스크 기록
AOF -> 모든 쓰기 명령을 로그로 기록 (파일커짐, 로딩 지연)
```

# 메모리 관리

## 메모리 오버커밋(Memory Overcommit)
forck() 호출 시 부모프로세스와 자식프로세스의 메모리 페이지를 공유(COW)한다.
따라서 실제 공간보다 적게 사용하므로 램이 부족해 보이더라도 자식프로세스에게 공간할당 요청을 허용한다.

```bash
vm.overcommit_memort = 0

0 - 기본값 (약간 오버커밋허용)
1 - 항상 허용
2 - 오버커밋 제한
```
